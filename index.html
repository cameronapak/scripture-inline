Getting started

1. Get an app key

Bible text comes from the YouVersion Platform, so cards and passages need a free app key. The key is public, so you can put it in page markup. Link mode works without one.

  1. Sign up at platform.youversion.com.
  2. Create an app and copy its app key.

2. Add the script

Add one script tag with your app key. It registers the components and finds references on the page.

Show Scripture for Bible references

The script finds references in the page's text, including abbreviations like "Rom 8:28-30", and makes each one a link. Links lay out exactly like the text they replace, so lines never reflow. Text in code, pre, links, form fields, and anything marked data-scripture-inline-ignore is skipped.

Passage

<si-passage> displays a passage with its required copyright attribution. Attributes choose what shows. CSS properties choose how it looks, so one rule can style every passage on a page.

Passage input

<si-passage-input> picks a book, chapter, verse, or range. Focus it to browse every book, or type: "Roman 8" finds Romans 8, and "Ps 119:" lists all 176 verses. Its value is the passage ID, it submits with a form under name, and it fires change with detail.passageId.

Value: (empty)
